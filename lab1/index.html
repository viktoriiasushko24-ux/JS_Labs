Лабораторна робота №1

Відкрийте консоль браузера: F12 → вкладка Console.

Тестові приклади з методички:

triangle(7, "leg", 18, "hypotenuse");
triangle(60, "opposite angle", 5, "leg");

Перевірка довільного порядку аргументів:

triangle(4, "leg", 8, "hypotenuse");
triangle(8, "hypotenuse", 4, "leg");

Перевірка некоректних значень (помилки):

// 1. Від'ємне чи нульове значення
triangle(43.13, "angle", -2, "hypotenuse");

// 2. Катет більший або рівний гіпотенузі
triangle(10, "leg", 5, "hypotenuse");

// 3. Негострий кут (>= 90°)
triangle(5, "leg", 90, "adjacent angle");

// 4. Помилка в назві типу або несумісні типи
triangle(5, "hypotenus", 10, "leg");
